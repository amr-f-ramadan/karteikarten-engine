# Lens Dock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the five-button tab bar with one glass knob that raises a swipeable pill of the five views, in both apps, without changing the apps' markup.

**Architecture:** Pure loop/settle arithmetic in `src/core/dock.js`; a `createDock(ctx, nav)` module in `src/ui/dock.js` that owns the knob, the drag, the glide, open/closed and the idle timer; the router gains `go(mode)` and hands `aria-current`/badge updates to `dock.refresh(dueN)`; `app.css` restyles the existing `<nav>` as the hidden pill.

**Tech Stack:** Vanilla ES modules bundled by esbuild (`npm run build`), `node --test` unit tests, Playwright browser suite (`tests/e2e.cjs`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-01-lens-dock-design.md`

## Global Constraints

- Engine holds no texts, colours or app checks: labels and icons come from the apps' `<nav>`; colours from app tokens (`--glass`, `--glass-strong`, `--rim`, `--shine`, `--shadow`, `--accent`, `--again`, `--muted`, `--ink`).
- Safari 15+ and current Chrome; no `:dir()`, no `scrollend`; logical CSS properties; RTL mirrors the x offset.
- One bundle under 60 KB; `npm run check` must pass; `app.js`/`app.js.map` committed with `src/`.
- Comments in the engine are German, explain why only.
- `prefers-reduced-motion`: pill, knob and label transitions off.
- Every push: `npm test` green, real numbers in the commit message; the de-karteikarten fingerprint diffed with `DUMP_RUN`.
- Timings from the spec: rise 0.4 s; sink after 240 ms (tap) / 520 ms (swipe); idle 3.5 s; glide 200 ms + 120 ms per slot, max 520 ms; flick projection 160 ms; tap threshold 6 px; slot 72 px; loop of five.

## Review Focus

1. A touch the browser cancels mid-swipe (`pointercancel`, lost capture): the row must still settle on an icon and the view must switch. Test in Task 3 (dispatch `pointercancel` after a partial drag).
2. Keyboard: Tab to a nav button and press Enter while the pill is closed: the view must switch and nothing may be left half-open. Test in Task 3 (`page.keyboard.press("Enter")` on a focused button).
3. A render while the pill is open (sync finishes, toast): the pill must stay open and in place; `refresh` must not rebuild the nav. Test in Task 3 (open, call `ctx.render` via a second sync, assert still open).
4. Due count changes (answering cards) must reach the knob's badge the same render. Test in Task 3 (answer a card, compare `#badge` and the knob badge).
5. An old `index.html` without changes: the knob is built from whatever `nav button[data-mode]` exist, any number. Covered by the e2e suite running both apps unchanged; Task 3 asserts the knob label equals the current button's text.

### Task 1: Loop and settle arithmetic in core

**Files:**
- Create: `src/core/dock.js`
- Test: `tests/unit/core.test.js`

**Interfaces:**
- Produces:
  - `nearestTurn(d, n)` → number: offset `d` (items) mapped into `[-n/2, n/2)` so an item is drawn at its nearest turn of a loop of `n`.
  - `settleTarget(pos, velocity, slotsPerPx, dir)` → integer: `Math.round(pos - velocity * dir * 160 * slotsPerPx)` (velocity in px/ms, `dir` 1 or -1).
  - `glideDuration(distance)` → ms: `Math.min(520, 200 + Math.abs(distance) * 120)`.

- [ ] **Step 1: Write the failing test** (append to `tests/unit/core.test.js`, import from `../../src/core/dock.js`)

```js
test("dock: a loop of five draws each item at its nearest turn, a lift settles on a slot", () => {
  assert.deepEqual([0, 1, 2, 3, 4, -1, -3, 7].map(d => nearestTurn(d, 5)), [0, 1, 2, -2, -1, -1, 2, 2]);
  assert.ok(Math.abs(nearestTurn(2.6, 5) + 2.4) < 1e-9);
  assert.equal(settleTarget(1.4, 0, 1 / 72, 1), 1, "no speed: nearest slot");
  assert.equal(settleTarget(1.4, -0.9, 1 / 72, 1), 3, "a flick to the left carries two slots further");
  assert.equal(settleTarget(1.4, -0.9, 1 / 72, -1), -1, "mirrored for RTL");
  assert.equal(glideDuration(0), 200); assert.equal(glideDuration(2), 440); assert.equal(glideDuration(9), 520);
});
```

- [ ] **Step 4: Implement `createDock(ctx, nav)` in `src/ui/dock.js`** (German header comment: why the knob, why pointer capture plus `elementFromPoint`, why the click fallback). Structure, one closure:
  - `items = [...nav.querySelectorAll("button[data-mode]")]`, `N = items.length`, `SLOT = 72`, `rtl = () => getComputedStyle(nav).direction === "rtl"`, `dir = () => rtl() ? -1 : 1`.
  - At creation, wrap each button's text nodes in `<span class="lbl">` (the apps' markup has bare text; the label must be hidden on the non-centred buttons without an app change). The label text for the knob comes from that span.
  - `pos` (fractional index of the centred slot, starts at the index of `S.mode`), `open`, `idleT`, `anim`, drag bookkeeping (`active, startX, startPos, moved, lastX, lastT, vel, lastRelease`).
  - `place()`: for each item `d = nearestTurn(i - pos, N)`, `x = d * SLOT * dir()`, `s = Math.max(0.8, 1.25 - |d| * 0.35)`, `transform = translate(x, on ? -3 : 0) scale(s)`, `opacity = |d| > 2.6 ? 0 : 1`, class `on` for `i === mod(Math.round(pos))`.
  - `glideTo(target)`: rAF loop with `glideDuration(target - pos)`, cubic ease-out, `place()` per frame, ends with `pos = target`.
  - `setOpen(on)`: toggle `nav.open`, `aria-hidden`, `body.dock-open`, `knob.aria-expanded`; on open `pos = index of S.mode; place(); idle()`; `idle()` arms 3500 ms → `setOpen(false)`.
  - `pick(target, how)`: `glideTo(target)`; `ctx.go(items[mod(target)].dataset.mode)`; arm `how === "tap" ? 240 : 520` ms → `setOpen(false)`.
  - Pointer handlers on `nav` as in the demo: capture on down (try/catch), move → `pos = startPos - dx * dir() / SLOT`, `moved` beyond 6 px, velocity from the last move; `pointerup`/`pointercancel`/`lostpointercapture` → `release(e)`: tapped = `!moved && e.type === "pointerup"` ? `document.elementFromPoint(e.clientX, e.clientY)?.closest("button[data-mode]")` : null; target = tapped ? `Math.round(pos) + nearestTurn(items.indexOf(tapped) - pos, N)` : `settleTarget(pos, vel, 1 / SLOT, dir())`; `pick(target, moved ? "swipe" : "tap")`.
  - `click` on `nav`: if `performance.now() - lastRelease < 120` return; a button → `pick(...)` as a tap (keyboard Enter and odd touch endings). `click` on the knob → `setOpen(true)`.
  - `refresh(dueN)`: as in Interfaces. Clone the SVG with `cloneNode(true)`; label = the button's `textContent` minus `#badge`'s text, trimmed.
  - Return `{ refresh }`.
