# Vendored skills: Superpowers 6.4.2

These folders are the skills of the Superpowers plugin (https://github.com/obra/superpowers, MIT, see LICENSE),
copied here as project skills so that every Claude Code session on this repository loads them, including sessions
where account plugins are not available. Do not edit them here; to update, copy `skills/` from a newer release.
Claude reads `using-superpowers/SKILL.md` at the start of each session (see CLAUDE.md) and invokes the others
with the Skill tool.
